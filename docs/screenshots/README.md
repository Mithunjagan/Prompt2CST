# Screenshots

Before publishing the repository or a LinkedIn post:

1. launch Prompt2CST at 100% or 125% Windows display scaling;
2. use a demo prompt without showing an API key;
3. capture the full liquid-glass workspace at 1440p or 1080p;
4. save the image here as `prompt2cst-workspace.png`;
5. add this line below the hero paragraph in the main README:

   ```markdown
   ![Prompt2CST RF design workspace](docs/screenshots/prompt2cst-workspace.png)
   ```

Use a preview result for the public screenshot. Do not expose keys, local user
names or proprietary CST projects.
