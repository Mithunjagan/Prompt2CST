# Screenshots

The repository hero currently uses:

```text
docs/screenshots/prompt2cst-workspace.png
```

Before replacing it or publishing another screenshot:

1. launch Prompt2CST at 100% or 125% Windows display scaling;
2. clear the OpenRouter key field or leave the masked placeholder visible;
3. use a non-proprietary demo prompt and preview result;
4. capture the complete workspace at 1440p or 1080p;
5. check the image for keys, local user names, private paths and CST projects;
6. replace `prompt2cst-workspace.png` without changing the README path.

Never publish an API key or proprietary CST design.
